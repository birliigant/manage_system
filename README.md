# 装修公司管理系统

面向装修企业内部使用的轻量级运营管理平台，提供客户、员工、账号、项目、施工阶段、供应商、材料采购和收款管理能力。

项目使用 Java 17 编写，后端内置 HTTP 服务和 REST 风格接口，前端使用原生 HTML/CSS/JavaScript，数据保存于本地 H2 文件数据库。

## 快速启动

在 macOS、Linux 或 Windows Git Bash 中执行：

```bash
bash ./start.sh
```

Windows PowerShell 可以通过 Git Bash 执行：

```powershell
bash .\start.sh
```

默认访问地址为 <http://localhost:8080/>。详细的清理、构建、端口配置和手动启动命令见[开发与运行](docs/开发与运行.md)。
