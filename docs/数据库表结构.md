# 装修公司管理系统数据库表结构

本文档根据当前项目中的 [`DatabaseManager.java`](src/main/java/org/example/db/DatabaseManager.java) 建表与迁移逻辑整理，描述项目当前实际使用的数据库表结构。

## 基本说明

- 数据库类型：`H2 2.2.224`
- JDBC URL 模式：`jdbc:h2:file:data/manage-system;AUTO_SERVER=TRUE;MODE=MySQL;DATABASE_TO_LOWER=TRUE`
- 主键类型：各表统一使用 `bigint auto_increment`
- 日期类型：`date`
- 时间类型：`timestamp`
- 大文本字段：`clob`
- 金额/面积字段：使用 `decimal`

## 表关系概览

- `users` 与 `user_sessions`：一对多
- `users.employee_id` 与 `employees.id`：逻辑关联，用于账号绑定员工；当前代码只加了字段，没有显式外键约束
- `customers` 与 `projects`：一对多
- `employees` 与 `projects`：一对多，一个员工可负责多个项目
- `projects` 与 `project_stages`：一对多，删除项目时级联删除阶段
- `projects` 与 `material_purchases`：一对多，删除项目时级联删除采购记录
- `projects` 与 `payment_records`：一对多，删除项目时级联删除收款记录
- `suppliers` 与 `material_purchases.supplier_id`：逻辑关联；当前代码只加了字段并做数据迁移，没有显式外键约束

## 外键清单

### 已声明的外键约束

| 约束名 | 来源表.字段 | 目标表.字段 | 删除规则 | 说明 |
| --- | --- | --- | --- | --- |
| `fk_sessions_user` | `user_sessions.user_id` | `users.id` | `on delete cascade` | 删除账号时自动删除登录会话 |
| `fk_projects_customer` | `projects.customer_id` | `customers.id` | 默认限制 | 项目必须关联客户 |
| `fk_projects_manager` | `projects.manager_id` | `employees.id` | 默认限制 | 项目必须关联负责人 |
| `fk_stages_project` | `project_stages.project_id` | `projects.id` | `on delete cascade` | 删除项目时自动删除施工阶段 |
| `fk_materials_project` | `material_purchases.project_id` | `projects.id` | `on delete cascade` | 删除项目时自动删除采购记录 |
| `fk_payments_project` | `payment_records.project_id` | `projects.id` | `on delete cascade` | 删除项目时自动删除收款记录 |

### 当前为逻辑关联、尚未声明 FK 的字段

| 来源表.字段 | 目标表.字段 | 当前状态 | 说明 |
| --- | --- | --- | --- |
| `users.employee_id` | `employees.id` | 仅字段级关联 | 用于员工和系统账号绑定，当前无数据库外键约束 |
| `material_purchases.supplier_id` | `suppliers.id` | 仅字段级关联 | 用于采购记录与供应商主数据关联，当前无数据库外键约束 |

## 1. users

用途：系统登录账号表，保存账号、密码哈希、角色、状态及员工绑定信息。

| 字段名 | 类型 | 非空 | 主键/约束 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `bigint auto_increment` | 是 | PK | 账号 ID |
| `username` | `varchar(64)` | 是 | UNIQUE | 登录用户名 |
| `display_name` | `varchar(64)` | 是 |  | 显示名称 |
| `password_hash` | `varchar(256)` | 是 |  | 密码哈希 |
| `password_salt` | `varchar(256)` | 是 |  | 密码盐值 |
| `role` | `varchar(32)` | 是 |  | 角色编码，如 `ADMIN` |
| `status` | `varchar(32)` | 是 |  | 账号状态，如“启用” |
| `created_at` | `timestamp` | 是 |  | 创建时间 |
| `employee_id` | `bigint` | 否 | 逻辑关联 | 绑定员工 ID，关联 `employees.id`，当前无显式 FK |

说明：

- 系统默认会初始化 `admin`、`manager`、`finance`、`designer` 四个账号
- `employee_id` 由迁移逻辑补充，用于把账号绑定到员工
- `employee_id` 当前没有 `foreign key` 约束，应用层通过查询与绑定逻辑保证一致性

## 约束与迁移补充说明

- `users.username` 唯一
- `user_sessions.token` 唯一
- `suppliers.name` 唯一
- `projects`、`project_stages`、`material_purchases`、`payment_records` 都与项目主表关联
- 当前代码中 `users.employee_id` 和 `material_purchases.supplier_id` 是先通过 `alter table add column` 补上的字段，没有在初始化 SQL 中声明外键约束
- 未声明 `on delete cascade` 的外键，默认按数据库限制处理，存在被引用记录时不能直接删除主表数据
- 删除 `users` 记录时，会级联删除其 `user_sessions`
- 删除 `projects` 记录时，会级联删除对应的施工阶段、采购记录和收款记录
