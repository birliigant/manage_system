# 装修企业运营管理平台接口文档

## 1. 基本说明

- 启动脚本：项目根目录可直接执行 `bash start.sh`
- 手动启动命令：

```bash
mkdir -p out
javac -encoding UTF-8 -cp lib/h2-2.2.224.jar -d out $(find src/main/java -name "*.java")
java -cp out:src/main/resources:lib/h2-2.2.224.jar org.example.Main
```

- 基础地址：`http://localhost:8080`
- 除 `POST /api/auth/login` 外，所有 `/api/**` 接口都需要登录
- 认证方式：

```http
Authorization: Bearer <token>
```

- 日期格式统一为：`yyyy-MM-dd`
- 金额字段统一为两位小数的十进制数值
- 统一返回结构：

```json
{
  "success": true,
  "message": "OK",
  "data": {}
}
```

当 `success=false` 时，`message` 为错误原因，`data=null`

## 2. 权限说明

| 角色 | 编码 | 说明 |
| --- | --- | --- |
| 管理员 | `ADMIN` | 拥有全部模块读写删权限 |
| 项目经理 | `MANAGER` | 可维护客户、项目、施工阶段、供应商、采购 |
| 财务 | `FINANCE` | 可维护收款 |
| 设计师 | `DESIGNER` | 可维护客户、项目、施工阶段 |

说明：

- 账号管理只允许管理员访问
- 系统面向企业内部使用，不开放外部自助注册
- 员工账号由管理员通过账号管理接口统一开通

## 3. 认证接口

### 3.1 登录

- 接口：`POST /api/auth/login`
- 作用：用户登录，返回 token 和当前用户信息

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |

返回值：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| token | string | 访问令牌 |
| expiresAt | string | 过期时间 |
| user | object | 当前用户信息 |

### 3.2 获取当前用户

- 接口：`GET /api/auth/me`
- 作用：获取当前 token 对应的用户信息

返回字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 用户 ID |
| username | string | 用户名 |
| displayName | string | 显示名称 |
| role | string | 角色编码 |
| permissions | array | 权限列表 |

### 3.3 退出登录

- 接口：`POST /api/auth/logout`
- 作用：注销当前登录会话

返回值：

```json
{
  "success": true,
  "message": "OK",
  "data": {
    "loggedOut": true
  }
}
```

### 3.4 获取权限概览

- 接口：`GET /api/auth/permissions`
- 作用：返回当前账号的角色和权限列表

### 7.1 查询账号列表

- 接口：`GET /api/users`
- 权限：`ADMIN`
- 作用：查询系统账号列表

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| keyword | string | 否 | 按用户名、显示名、角色、绑定员工搜索 |

返回字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 账号 ID |
| username | string | 登录用户名 |
| displayName | string | 显示名称 |
| role | string | 角色编码 |
| status | string | 账号状态 |
| createdAt | string | 创建时间 |
| employeeId | number/null | 绑定员工 ID |
| employeeName | string | 绑定员工姓名 |
| employeeRole | string | 绑定员工岗位 |

### 7.2 获取账号详情

- 接口：`GET /api/users/{id}`
- 权限：`ADMIN`

### 7.3 新增账号

- 接口：`POST /api/users`
- 权限：`ADMIN`
- 作用：管理员为内部员工开通系统账号

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 登录用户名，必须唯一 |
| displayName | string | 是 | 显示名称 |
| employeeId | number | 否 | 绑定员工 ID，同一员工只能绑定一个账号 |
| role | string | 是 | 角色，取值 `ADMIN / MANAGER / FINANCE / DESIGNER` |
| status | string | 否 | 状态，默认 `启用` |
| password | string | 是 | 登录密码 |

### 7.4 更新账号

- 接口：`PUT /api/users/{id}`
- 权限：`ADMIN`

请求体与新增类似，差异如下：

- `password` 可为空
- `password` 为空时表示不修改密码

### 7.5 删除账号

- 接口：`DELETE /api/users/{id}`
- 权限：`ADMIN`

### 7.6 重置账号密码

- 接口：`POST /api/users/{id}/reset-password`
- 权限：`ADMIN`
- 作用：管理员为指定账号直接设置新密码

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| password | string | 是 | 新密码，至少 6 位 |

说明：

- 系统不会返回也不会展示账号当前密码
- 管理员只能为账号设置新密码，不能查看历史密码
